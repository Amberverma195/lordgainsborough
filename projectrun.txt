Backend secrets are saved as Windows user environment variables.
You do not need to paste them every time.

If you just saved or changed the environment variables, open a new PowerShell
window before starting the backend.

Start the backend:

  cd D:\Projects\Websites\LordGainsBorough\Code\backend
  .\mvnw.cmd spring-boot:run

Start the frontend in a second PowerShell window:

  cd D:\Projects\Websites\LordGainsBorough\Code\frontend
  npm run dev

Local URLs:

  Frontend: http://localhost:3000
  Backend:  http://localhost:8082
  Menu API: http://localhost:8082/api/menu

Environment variables used by the backend:

  DB_HOST
  DB_PORT (optional; defaults to 5432)
  DB_NAME (defaults to postgres)
  DB_USER
  DB_PASSWORD
  DB_SSL_MODE (optional; defaults to prefer; use require for Supabase)
  MAIL_USERNAME
  MAIL_PASSWORD
  JWT_SECRET
  ABUSE_IP_HASH_SECRET

To check that they exist without printing secret values:

  'DB_HOST','DB_NAME','DB_USER','DB_PASSWORD','MAIL_USERNAME','MAIL_PASSWORD','JWT_SECRET','ABUSE_IP_HASH_SECRET' |
    ForEach-Object { "$_ = " + [bool][Environment]::GetEnvironmentVariable($_, 'User') }
